# SIRAJ Desktop Dashboard V1

## الهدف

تقديم واجهة سطح مكتب عربية على Windows تعرض الحالة الفعلية لمشروعات سراج، مع تركيز أولي على إدارة إنتاج الحلقات والوصول إلى قائمة **الحلقات الجاهزة للتحويل إلى فيديو جاهز للنشر على يوتيوب**.

## التقنية

- Python 3.13
- PySide6 / Qt Widgets
- قراءة مباشرة من ملفات المستودع؛ لا توجد قاعدة بيانات تجريبية مخفية.
- الاعتماد `PySide6` اختياري ضمن مجموعة `desktop` حتى لا يتغير مسار التشغيل الأساسي لسراج.

## ما تنفذه V1

1. لوحة تحكم داكنة عربية مستندة إلى التصور البصري المعتمد.
2. اكتشاف مجلدات `projects/episode-*` تلقائيًا.
3. قراءة بيان إنتاج الفيديو وتحديد عدد اللقطات والمدة والنموذج والمزوّد.
4. تصنيف الحلقة إلى: مسودة، قيد الإعداد، جاهزة للتحويل، قيد مراجعة الفيديو، جاهزة للنشر، أو معلّقة.
5. قائمة مركزية للحلقات الجاهزة للتحويل.
6. معاينة placeholder آمنة لحين وجود ملف فيديو فعلي.
7. عرض المخرجات والسجل والمقاييس والنشاطات الأخيرة.
8. منع التنفيذ المدفوع في هذه المرحلة؛ زر التحويل يفتح بوابة معلومات فقط.

## قاعدة الجاهزية

لا تعرض الحلقة على أنها جاهزة للتحويل إلا عند تحقق اعتماد الصورة الرئيسية والاعتماد البصري النهائي ورفع حظر توليد الحلقة الكاملة في بيان الإنتاج. ولا تعرض أنها جاهزة للنشر إلا عند وجود ملف الفيديو النهائي وإيصال اعتماد نشر صريح.
