# Adam Non-Quran Research Harvest v1

This stage covers every remaining event outside the Quran-explicit batch and the
three already approved gap decisions:

- fourteen factual research events;
- one editorial transition event, EV-ADAM-099.

The local run scans tracked and untracked project text artifacts, captures
event/question-linked snippets with file and excerpt checksums, deduplicates
them, ranks them for research review, and generates three combined ChatGPT and
NotebookLM prompt batches.

Source hints are heuristic only. They are not hadith grades, source-origin
classifications, adjudications, or approvals. Raw excerpts are retained only in
the local report. The tracked repository receives the runtime, tests, prompt
policy, backlog, and blank editorial template, without treating local excerpts
as approved evidence.
