# Adam Non-Quran Source Verification Execution v1

This stage converts the structurally selected candidate pool into an execution
queue for actual human source verification.

It consolidates duplicate candidates within each event by deterministic
verification keys, creates one blank verification record for every canonical
representative, routes factual events to locator verification, source-mention
expansion, or focused discovery, and keeps EV-ADAM-099 editorial-only.

A verification record is not accepted until an authorized original source has
been opened and the exact source locator, excerpt, surrounding context, source
material checksum, excerpt checksum, method, verifier, and time have been
recorded. Hadith authentication and source-origin classification remain
separate qualified-human actions.

This stage does not authenticate sources, grade reports, approve evidence,
complete adjudication, open the evidence gate, or enable providers.
