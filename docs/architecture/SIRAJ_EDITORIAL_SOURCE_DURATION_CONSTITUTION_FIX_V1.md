# SIRAJ Editorial Source Hierarchy and Duration Constitution Fix V1

This corrective release binds the autonomous editorial pipeline to two existing
SIRAJ constitutional laws.

## Source hierarchy

1. The selected local Al-Maktaba Al-Shamela books are the primary information
   corpus.
2. SIRAJ builds a bounded local context from the selected shortlist, local book
   databases, and existing episode source packages.
3. The evidence request is blocked before a paid OpenAI call when the local
   primary context is insufficient.
4. Web search remains available only to fill explicit gaps left by the selected
   Shamela books. It is not the default evidence corpus.

## Duration

- Minimum episode duration: 18 minutes.
- Target episode duration: 22 minutes.
- Maximum episode duration: 25 minutes.
- Script target and segment-sum validation both enforce 1,080–1,500 seconds.

## Safety

- No OpenAI, Runware, or ElevenLabs request occurs during publication or audit.
- The episode hard cap remains USD 40.
- Music remains forbidden.
- The existing two human gates remain unchanged.
