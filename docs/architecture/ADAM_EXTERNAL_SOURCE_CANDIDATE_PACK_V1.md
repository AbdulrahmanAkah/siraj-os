# Adam External Source Candidate Pack v1

This stage materializes an externally researched candidate source layer for all
fourteen unresolved factual non-Quran events.

The catalog contains Quran verse anchors and hadith collection record locators.
Each anchor is normalized and checksummed, but it is not treated as a
human-compared exact source excerpt. The event pack separates explicit claims
from supported synthesis and scholarly interpretation, and records scope limits
for chronology, unseen detail, and narration.

The local run also compares the eighty existing verification templates against
the twenty-two researched source candidates. Auto-match confidence only reduces
manual search. It never verifies, authenticates, grades, classifies, or approves
a source.

Before any candidate becomes `source_verified`, a human must open an authorized
source, record the exact excerpt and context, compute source/excerpt checksums,
record the verification method and identity, and separately record any hadith
authentication or source-origin decision.
