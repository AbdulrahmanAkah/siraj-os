# Adam Source Review Workbench v1

This stage creates a dependency-free local HTML workbench for the twenty-two
Adam Quran and hadith source candidates.

The page embeds the current review docket, source-resolution records, event
links, external source URLs, local archive links, research anchors, machine
extractions, and suggested exact-text passages. Drafts are retained in browser
local storage and can be imported or exported as JSON.

No decision is selected by default. The final export remains disabled until all
twenty-two records pass browser validation and the exact limited human-approval
phrase is entered. The Python validator is authoritative before repository
ingestion.

This stage does not grade hadith, authenticate reports, classify source origin,
approve event binding, approve the episode evidence package, open the evidence
gate, or enable providers.
