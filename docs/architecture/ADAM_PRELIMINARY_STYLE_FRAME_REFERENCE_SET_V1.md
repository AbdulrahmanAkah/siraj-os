- paid, direct, live-provider, or Runware execution.

- source: `ADAM-PREF-001`;

- 8–12 seconds;
- one output only;
- camera, water, foliage, mist, light, and depth motion only;
- no audio, music, voice, dialogue, or full-episode generation.
