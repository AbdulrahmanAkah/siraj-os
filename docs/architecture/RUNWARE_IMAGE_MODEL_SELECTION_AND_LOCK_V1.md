# Runware Image Model Selection and Lock V1

Human-approved bakeoff decision:

- Primary: Seedream 5.0 Pro (`bytedance:seedream@5.0-pro`)
- Secondary: Nano Banana 2 (`google:4@3`)
- Excluded: FLUX.2 Pro (`bfl:5@1`)

Seedream handles environments, interiors, symbolic-safe scenes, dynamic action, architecture and materials. Nano Banana 2 handles close-ups, crowds, character consistency, reference-guided editing, and complex human interaction. Graphics and generated video remain in their own pipelines. Every image request asks Runware to return cost.
