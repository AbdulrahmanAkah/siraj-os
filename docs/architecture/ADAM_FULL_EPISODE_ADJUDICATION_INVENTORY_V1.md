# Adam Full-Episode Adjudication Inventory v1

This stage inventories all 37 Adam events in one pass.

It combines:

- the tracked event map;
- classified source records;
- the creator's limited human approval for three gap decisions;
- metadata-only scans of tracked and local untracked project artifacts.

It produces an event-by-event readiness ledger, a source-binding backlog, and a
prioritized next review batch. It intentionally retains no raw source text and
cannot approve evidence, open the evidence gate, or enable providers.
