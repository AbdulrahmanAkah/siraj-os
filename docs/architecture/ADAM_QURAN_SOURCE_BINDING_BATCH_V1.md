# Adam Quran Source Binding Batch v1

This batch materializes the Quran-source layer for all nineteen Adam events
already classified as `quran_explicit` by the full-episode inventory.

It records:

- exact surah and ayah locators;
- normalized Arabic reference anchors;
- deterministic source and excerpt checksums;
- event-specific claim scope;
- explicit exclusions preventing tafsir or chronology from being smuggled into
  Quran-only evidence;
- one blank human-review template covering the full nineteen-event batch.

This stage is not an approved evidence package. The normalized anchors still
require human comparison against an authorized Mushaf source. No human decision
is prefilled, the full episode remains incomplete, and the evidence gate remains
withheld.
