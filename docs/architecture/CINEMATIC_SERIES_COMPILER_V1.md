# Cinematic Series Compiler v1 — Superseded

This document described the first deterministic compiler baseline.

Its fixed category reservations and fixed generated-video target have been
removed. The current architecture is documented in:

`docs/architecture/CINEMATIC_SERIES_COMPILER_V2.md`

The active design keeps only the USD 40 target, USD 45 hard cap, and 300-second
video ceiling fixed. Media-category spending and generated-video duration are
decided dynamically from editorial demand and priced options.
