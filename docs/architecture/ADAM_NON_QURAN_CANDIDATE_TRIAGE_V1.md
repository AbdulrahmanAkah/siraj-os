# Adam Non-Quran Candidate Triage v1

This stage converts the 190-candidate local harvest into a manageable manual
source-verification queue.

The triage is structural only. It detects source locator signals, source
mentions, research notes, internal schema/policy echoes, and editorial context.
It selects at most eight candidates for each factual event and excludes
EV-ADAM-099 from factual source verification.

The triage does not authenticate a source, grade a hadith, determine whether a
report is marfu or Isra'iliyyat, approve an event disposition, or open the
evidence gate. Human source verification remains required.
