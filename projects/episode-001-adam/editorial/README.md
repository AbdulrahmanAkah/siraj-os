## قواعد مهمة

- مدة الحلقة القياسية 18–25 دقيقة.
- الهدف المتوسط 22 دقيقة.
- توقيت الأحداث تقديري.
- تقسيم الحلقات غير ملزم.
- كتب التاريخ وقصص الأنبياء مصادر رئيسية مع تصنيف أخبارها.
- الإسرائيليات المقبولة أو المسكوت عنها يجب وسمها.
- الدرر السنية غير معتمدة للتصحيح والتضعيف في هذا المشروع.
