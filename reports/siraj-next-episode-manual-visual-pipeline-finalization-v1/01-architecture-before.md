# Architecture before

- Canonical and legacy state authorities competed for control of episode progress.
- The reusable state model encoded an episode-specific lifecycle and provider-first visual stages.
- No durable canonical profile existed for user-produced visual assets.
- There was no complete manual handoff, validated ingest, immutable asset ledger, SHA-bound visual lock, or generic post-ingest assembly workflow.
- Desktop surfaces still exposed legacy provider-oriented behavior as the dominant route.
- Generic pre-visual helpers retained episode-specific presentation assumptions.
- Dependency freshness was not enforced at every downstream gate.

The legacy EP001/EP002 code and historical evidence were preserved. They are compatibility material, not authority for a new episode.
