# Shorts Derivative Engine V1 Certification Packet

This directory is reserved for offline, hash-bound certification evidence.

The reports are generated by:

`python scripts/certify_shorts_derivative_engine_v1.py --repo .`

No report in this directory authorizes provider execution, paid execution,
network production calls, real-episode rendering, upload, or publication.

The V1 direct-use activation packet is recorded in:

- `SHORTS_REAL_USE_READINESS_GAP_AUDIT_V1.json`
- `SHORTS_CONFLICT_MATRIX_V1.json`
- `SHORTS_GAP_ENFORCEMENT_MATRIX_V1.json`
- `SHORTS_DEPENDENCY_APPROVAL_INVALIDATION_MODEL_V1.json`
- `SHORTS_ENGINE_REAL_USE_READINESS_CERTIFICATION_V1.json`
- `SHORTS_REAL_USE_READINESS_FINAL_REPORT_V1.md`

- `SHORTS_DESKTOP_UX_GAP_ENFORCEMENT_MATRIX_V1.json`
